## 业务与数据库交接

- 项目编号由数据库序列自动生成，项目编号列保持非空唯一约束；并发分配使用 `nextval`，客户端不能直接调用编号生成器或指定编号。项目创建审计保存包含项目编号的完整新记录快照。
- 项目保持一个主责经营实体和多个参与经营实体。`site_project_create` 在一个数据库事务中同时创建项目主体及初始实体关系，参与实体校验或保存失败时整次调用回滚，重复实体自动去重。
- 外协申请只允许通过 `site_project_apply` 创建；暂停、待关闭或关闭项目会被 RPC 状态检查拒绝，authenticated/anon 的直接 REST INSERT 权限已撤销，不能绕过。
- 项目支持在建转暂停、暂停复工、显式关闭以及关闭后重新开启。已关闭项目只能重新开启为 `active`；重新开启会清理 `actual_end_date`、`closed_at`、`closed_by`、关闭原因及暂停字段。
- 月报 `completed` 只生成提醒，不会自动关闭正式项目。状态改变必须填写原因，并记录操作者、时间、前状态和后状态；既有申请、培训和审计记录不会被重开操作覆盖。
- 项目进入暂停、待关闭或关闭状态时，当前邀请码永久撤销。重新开启不会恢复旧邀请码，必须显式生成新邀请码。
- 项目详情页复用 `site_project_audit_logs` 展示只读状态历史。合法项目角色按现有 `site_project_can_read` RLS 读取；跨项目、跨经营实体记录不可读。authenticated 仅有 SELECT，anon 无表权限；页面兼容无记录、失效账号和旧审计结构。
