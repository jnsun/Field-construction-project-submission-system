## 二、Bug 清单与修复（均已提交 commit 571f893，Pages 已更新）

| 级别 | 位置 | 问题 | 修复 |
|---|---|---|---|
| P0 | exam_submit RPC | `v_qid` 声明 UUID，`p_answers->>v_qid` 无操作符，**交卷 100% 失败** | v_qid 改 TEXT；查库/写错题本处 `::uuid` 显式转换 |
| P1 | exam_start RPC | ongoing 先 RAISE，续考 RETURN 成死代码 → 中途退出被锁死且无超时结算 | 顺序改为 已通过→续考→次数用完；续考返回补 total_score |
| P1 | exam_start RPC | 续考返回缺 total_score（前端会显示"共 undefined 题"） | 已随上条一并补上 |
| P2 | papers.js | 随机卷数量/分值输入不触发重算，总分滞后且 save() 用陈旧值校验及格线 | `.pr-count/.pr-score` 绑 oninput/onchange → updateTotal() |
| P2 | papers.js | 「已选题目（N）」计数不随加题/删题刷新 | label 内加 `span#pf-picked-count`，renderPicked 同步 |
| P2 | mine.js | auto 模式学完提示"系统已自动记录本次培训"误导（应去考试） | training_my_trainings 返回 exam_mode，按模式显示两种文案 |
