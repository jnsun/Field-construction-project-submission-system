- **[P1] 员工端 assignment 无本人过滤**：RLS 下员工可读全计划 16 条 assignment，前端 asgMap 以「最后一行覆盖」取值——顺序变化时会展示他人的考试状态，签字调用可能落到别人 assignment 上。已改为双通道过滤（user_id 快照 OR employee_id 实时绑定，与 training_my_plan_ids 同口径）。
